Questions, answered.

What does it do?

It puts a live progress pane beside the chat: the goal, the stages, what done means, and where the work is now. It reads the session and draws. It never touches your code.

Where does it work?

In Claude Code, in the Claude desktop app. The terminal and the editor extensions have no side pane. Codex plugins cannot add one yet.

What does it cost?

Nothing to install: it is open source, MIT, and runs on the Claude plan you have. No API key, no new account. It uses a few tokens per stage change, far fewer than asking for a recap.

Does it fit my kind of work?

Yes. Pick one of ten templates, or let the agent write the stages for your mission. The agent can also save your own stages as a template.

Does it send anything home?

Anonymous usage numbers, never your words, files or names. The onboarding shows the switch, on by default; turn it off there or with /pane-metrics off. Each field is listed in docs/telemetry.md.

How do I update or remove it?

It updates itself between turns. To remove it, run /plugin uninstall mission-status@mission-status.
