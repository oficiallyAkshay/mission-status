# Site brief

The build brief for the mission-status site (Hastkala, page-skeletons section 8 with 8a for a landing page).

|---|---|
| Job of the page | Show, in one look, that you can know where your agent stands without reading through its work. |
| Who | People who run Claude Code sessions in the desktop app and lose track of them in long chats. |
| Headline | Know where your agent stands, without reading through its work. |
| Sub-line | One live view of the stages and the outcome, for any kind of work, that updates itself. |
| Stand | Agents show you their work. You only need to know where it stands. |
| Approach | A demo. The hero is the product itself, interactive, with sample data. |
| Skeleton | Product first: a full-width headline, one row of mission tabs, and under it a large Claude window that bleeds off the left and the bottom, with the pane fully visible. |
| Sections below the hero | Without it and with it, side by side (live counts); any mission and any shape (the agent adds a stage); a diagonal texture of real pane renders across templates and stages; the repository numbers (stars and forks from GitHub, clones and views from the clonometer files); footer with the build and security badges. |
| Owned motif | The pane itself: the stage track, the stage cards and the "Done when" gate lines, drawn by the plugin's own `bars.ts`. |
| Palette | Warm paper and ink for the page; the pane keeps its own dark look; one accent, the pane's purple `#8B7CF6`; green only for done. The site studio's no-purple check is skipped on purpose: Hastkala SX07 takes the product's own colour. |
| Type | The system sans (San Francisco on a Mac), one family, 800 for the headline. No web font to load. |
| Proof | The demo runs the real drawing code. Every number on the page is from a sample session and is labelled "sample". |
| Not on the page | Pricing, sign-up, testimonials, "we". The footer keeps the build and security badges (owner, 2026-11-25). |
| States | No script: a still of the pane. Reduced motion: no auto-play, no scrolling chat; stages change only on click. |
